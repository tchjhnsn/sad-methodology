The bridge

How sub-phase 7 hands off to the Ralph Loop

The six remaining articulation artifacts pair to produce one downstream deliverable each: a pre-loop handoff document. The handoff doc is the prompt the Ralph Loop reads at the start of every iteration. It points at the canonical specs; it does not duplicate them.

Input · articulation
Six artifacts
VERIFICATION_SPEC §9 (test plan), schema audit, ingestion spec, query interface spec, updated build roadmap, updated articulation closure inventory.
→
Pre-loop handoff
One bridge document
Names the completion condition (§9.16). Points at each spec for detail. Lists the per-iteration loop: read state, pick next failing test, fix, retest, commit. References the brand-load-bearing decisions and the V1.x deferrals.
→
Output · build
Ralph Loop iterations
Anthropic's ralph-wiggum plugin (Claude Code) reads the handoff, executes one iteration, the stop-hook re-feeds the prompt. Repeat until §9 says "every test passes."
